## About

I build practical software and network-security tooling, with a focus on the space where **enterprise networking, automation, backend engineering, and defensive security** meet.

My work includes endpoint posture and compliance, NetFlow-based anomaly detection, security workflow integrations, and network automation. I care about understanding how systems behave, documenting design decisions, and making projects reproducible rather than presenting demos without context.

**My workflow:** Learn → Design → Build → Test → Document → Iterate

## What I Value in a Project

- **Clarity:** explain the problem, architecture, setup, and limitations.
- **Reproducibility:** provide practical setup instructions and configuration examples without committing secrets.
- **Security:** keep credentials and sensitive environment details out of source control.
- **Evidence:** distinguish implemented features from planned work and validate claims with tests or demonstrations.
- **Maintainability:** prefer understandable code, focused changes, and useful documentation.
